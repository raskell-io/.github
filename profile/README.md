## How we build

The best tools disappear into the background. They work out of the box, have sane defaults, and stay
boring where boring is reliable. We build the right amount of complexity: simple when the problem is
simple, precise when the problem demands it.

We are stack-agnostic on purpose. Rust, Haskell, Elixir, Gleam, TypeScript, whatever fits. AI is
treated the same way: a powerful tool, not a religion.

We try a lot of ideas, ship them small and real, and see which ones stick. Some become serious projects.
Some stay fun. Both are fine.

## Secure edge infrastructure

- **[Zentinel](https://zentinelproxy.io)** ([GitHub](https://github.com/zentinelproxy/zentinel)): a security-first reverse proxy on Cloudflare's Pingora, with isolated security agents.
- **[Sango](https://sango.raskell.io)** ([GitHub](https://github.com/raskell-io/sango)): operator-grade edge diagnostics: TLS, HTTP/3, security headers, latency.
- **[Vela](https://github.com/raskell-io/vela)**: no-downtime app deployment on bare metal. One binary, no containers.

## Languages and tooling

- **[Arcanist.sh](https://arcanist.sh)** ([GitHub](https://github.com/arcanist-sh)): Haskell tooling built in Rust. [hx](https://hx.arcanist.sh) is a fast package and project manager; [bhc](https://bhc.arcanist.sh) is the Basel Haskell Compiler.
- **[Refrakt](https://refrakt.raskell.io)** ([GitHub](https://github.com/raskell-io/refrakt)): a convention-first web framework for Gleam.
- **[WASM-AD](https://wasmad.raskell.io)** ([GitHub](https://github.com/raskell-io/wasm-ad)): a fantasy console standard whose cartridges are WebAssembly modules.
- **[seijaku](https://github.com/raskell-io/seijaku)**: 静寂 the zero-JavaScript Zola theme behind raskell.io.

## Local-first apps and games

Things you can open right now. Your data stays on your device; the games run in the browser.

- **[Kurumi](https://kurumi.raskell.io)** ([GitHub](https://github.com/raskell-io/kurumi)): a local-first, AI-native second brain that works offline.
- **[Manabi](https://manabi.raskell.io)** ([GitHub](https://github.com/raskell-io/manabi)): 学 a reading-first language-learning app for Chinese, Japanese, and Hebrew.
- **[Paw & Claw](https://pawandclaw.raskell.io)** ([GitHub](https://github.com/raskell-io/paw-and-claw)): turn-based tactics in the spirit of Advance Wars, fought by woodland armies.
- **[Rainbow River](https://rainbowriver.raskell.io)** ([GitHub](https://github.com/raskell-io/rainbow-river)): a handheld-era fishing game, and the first WASM-AD cartridge.
- **[Terrarium](https://terrarium.raskell.io)** ([GitHub](https://github.com/raskell-io/terrarium)): a simulation where LLM-powered agents form emergent societies.
- **[broodwar.live](https://broodwar.live)** ([GitHub](https://github.com/broodwar-live)): the community platform for StarCraft: Brood War.
